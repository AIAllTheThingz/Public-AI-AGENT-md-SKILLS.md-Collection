# User Journey Standard

## Purpose

Trace how an intended user or actor pursues a goal across tasks and touchpoints.

## Required behavior

- Map `User -> Goal -> Journey -> Task -> Workflow / Interface -> Interaction -> Result`.
- Link journeys to product requirements and identify entry, exit, dependencies, channels, handoffs, and ownership.
- Cover applicable success, error, empty, loading, interruption, permission, timeout, abandonment, and recovery paths.
- Distinguish observed journeys from proposed or synthetic flows and record excluded users or contexts.

## Required evidence

Versioned journey record, evidence basis, linked requirements, critical states, findings, owner, and review trigger.

## Completion gate

Do not report a journey validated when it is only proposed or when material failure and recovery paths remain undefined.
