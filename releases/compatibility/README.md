# Release Compatibility Inventories

This directory contains machine-readable compatibility inventories for release candidates and stable releases that need an explicit contract review.

Each inventory identifies the published migration checkpoint, stable repository paths and contract classes, schema/template/tool surfaces, stable package boundaries, baseline exclusions, migration expectations, and final-release gates that remain deliberately unclaimed.

The inventory is evidence for compatibility review. It does not replace release notes, migration notes, permanent CI, independent specialist review, or publication verification.
