# Release Compatibility Inventories

This directory contains machine-readable compatibility inventories for release candidates and stable releases that need an explicit contract review.

The `1.0.0-rc.1` gate separates published `v0.10.0` evidence into focused checkpoints for stable paths and identifiers, normative rule contracts, tool behavior, and public finding-code interfaces. The candidate inventory pins those immutable checkpoint files and records stable package boundaries, baseline exclusions, migration expectations, and final-release gates that remain deliberately unclaimed.

These inventories are evidence for compatibility review. They do not replace release notes, migration notes, permanent CI, independent specialist review, or publication verification.
