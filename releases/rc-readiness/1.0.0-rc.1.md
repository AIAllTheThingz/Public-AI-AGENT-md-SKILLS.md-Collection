## Review findings

PR #71 has received **fifty-five material P1 findings and five material P2 findings** during preparation.

The latest P1 remediations are:

48. Alpha-normalization was hardened so same-shaped private locals used in the same semantic scope receive distinct identities instead of collapsing to one binding.
49. Shared reachability semantics model terminating `try`/`except`/`else`/`finally` paths for both literal and caller-supplied finding occurrences.
50. Caller-supplied finding call-site contracts record branch polarity such as `if:true` versus `if:false`, so moving a published call into the opposite branch changes its contract.
51. Every common stable CLI's real command boundary must return validation-failure exit code `1` for a failed `ToolResult`; this protects CLI behavior independently of the shared model implementation.
52. The permanent validation workflow is read-only, uses `persist-credentials: false`, and validates the exact PR head repository/SHA, removing the temporary write-token exposure and preserving fork-PR operation.
53. The temporary write-capable history-bundle staging workflow was removed from the active lineage after producing the authenticated bundle; no PR-controlled validation runs with repository write credentials.
54. Infinite-loop reachability now ignores `break` statements that exist only on statically unreachable paths such as `if False: break`, so a truly non-breaking `while True` correctly makes later findings unreachable.
55. `try` reachability recognizes obviously non-raising terminal returns such as `return None`; an unreachable exception handler can no longer make a following published finding look reachable.

The fifth P2 remediation keeps local identities stable when unrelated unused same-shaped locals are inserted, while still distinguishing multiple semantically loaded locals that share the same first-binding shape. The fourth P2 remediation packages authenticated compatibility history so the full validation suite can run from shallow clones and extracted source archives without depending on pre-existing full Git history. The three earlier P2 remediations preserve compatible finding-message edits, alpha-equivalent private renames, and discoverable/authenticated agent-skill checkpoint evidence.
