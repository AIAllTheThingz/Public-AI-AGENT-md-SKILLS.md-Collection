## Material findings

### Languages and runtimes

- PowerShell 7.6 is the current LTS family and follows the .NET 10 lifecycle. PowerShell 7.5 and 7.4 remain supported only inside their published lifecycle windows.
- C# 14 remains the released language boundary paired with .NET 10.
- .NET 10 remains an LTS release with support through November 2028.
- HashiCorp documentation identifies Terraform 1.15.x as the current CLI documentation line.
- OpenTofu 1.12 is a current released OpenTofu line.
- JavaScript/TypeScript, Python, Java, Go, Rust, Bash, and SQL were not reviewed in this pass and remain `NotRun` rather than being inferred current.

### Platforms

- Docker Engine 29 is an active 2026 release family with current security and runtime updates.
- Kubernetes 1.36 was released in April 2026. The repository must continue requiring exact provider/distribution version verification rather than implying that upstream minor status proves managed-service support.
- Azure, AWS, and Google Cloud Well-Architected guidance remains current and continues to emphasize explicit architecture tradeoffs, reliability, security, operations, performance, and cost boundaries.

### Virtualization

- Broadcom VCF PowerCLI is the continuation of VMware.PowerCLI. Current Broadcom Developer documentation uses the VCF PowerCLI naming and migration path.
- XenServer 9 is the current GA family. XenServer 8 and Citrix Hypervisor references are retained for installed/legacy estates, not as the default greenfield release boundary.
- Proxmox VE 9.x is the current major family; Proxmox announced PVE 9.2 in May 2026.
- XCP-ng 8.3 is the current LTS family and is supported through November 2028 according to current project documentation.
- Upstream KVM guidance remains current, but distribution kernel, QEMU, libvirt, firmware, and hardware compatibility remain distribution-specific.
- Nutanix lifecycle policy generally covers AHV alongside AOS/NCI families. Current detailed certified build/interoperability data still depends on the Nutanix Support Portal.
- Microsoft Hyper-V remains documented across supported Windows Server generations. Exact feature availability remains host-version specific.
- Red Hat Virtualization is in Extended Life Phase. Current Red Hat policy describes limited support with no new bug fixes, security fixes, hardware enablement, or root-cause analysis; OpenShift Virtualization is the continuity roadmap. An older repository sentence that attached an exact August 31, 2026 software-fix date was not supported by the current policy page and must not be retained as current fact.
- Oracle Linux 10 KVM documentation is current. Oracle's current KVM documentation identifies Oracle Linux Virtualization Manager availability with Oracle Linux 8, so OLVM must be treated as a separate legacy managed boundary rather than implied as a current Oracle Linux 10 management plane.
- Live Broadcom vSphere product documentation retrieval was blocked. The vSphere package therefore remains `NotRun` in `SOURCE_REVIEWS.json` even though its VCF PowerCLI sub-boundary was reviewed.

### Operating systems

- Windows Server 2016 remains in extended support until January 2027.
- Windows Server 2019 remains an extended-support generation.
- Windows Server 2022 mainstream support ends in October 2026 and extended support continues afterward.
- Windows Server 2025 is the current LTSC generation with published support into 2034.
- General Windows 10 support ended October 14, 2025. Current Windows 10 use requires an applicable LTSC/ESU or an explicitly owned exception/migration boundary. The existing Windows client package already reflects this accurately.
- RHEL lifecycle documentation remains current for RHEL 8, 9, and 10. Rebuild distributions require their own lifecycle verification.
- Ubuntu 26.04 LTS is the current 2026 LTS generation.
- Debian 13 `trixie` is current stable; Debian 13.6 was published in July 2026.
- SLES 15 SP7 is a current supported service pack and remains subject to SUSE's service-pack/LTSS lifecycle boundaries.
- Oracle Linux 10 documentation and current lifetime-support guidance were reviewed.
- Apple published current macOS Tahoe 26 security updates and 2026 Platform Security guidance.
- FreeBSD 15.1 is a current production release as of June 2026.

### Networking

- HPE Aruba AOS-CX 10.16 is a current long-supported release line with 2026 documentation. Exact hardware support remains model-specific.
- Cisco introduced calendar-based IOS XE 26.x naming in 2026. IOS XE 26.1.1 is available, while IOS XE 17.x trains remain relevant to supported platform-specific deployments. Repository guidance must require exact platform/train verification rather than declaring one universal approved train.
- Juniper's current Junos lifecycle material includes active 2026 release milestones and remains platform/support-contract specific.
- Broadcom's current Fabric OS public catalog includes Fabric OS 10.x documentation and FOS 10.0.1 release notes dated June 2026. Exact switch, SANnav, HBA, storage-array, and upgrade-hop interoperability remains matrix-specific.
